Nookly is pages, blocks, tables, and kanban boards in one lightweight app. It opens instantly because it never talks to a server.

The source code is closed. This repository is a product showcase and release notes.

**Data is stored locally in SQLite.** The database file can be copied, moved, and opened on another computer even a year from now, with no network and no account.

---

## Write the way you think

Text, headings, lists, checkboxes, quotes, dividers, code with syntax highlighting, and images. A slash command changes the block type on the fly, no mouse needed.

## What else is inside

- **Page tree**: any depth, with emoji icons and drag and drop
- **Offline**: not a single byte leaves your device
- **Responsive interface**: the sidebar hides on narrow screens

## Download

One archive and the app is ready. Files are in [Releases](https://github.com/nooklyru/nookly-release/releases).

| Platform | File | How to run |
|---|---|---|
| Windows x64 | `nookly-0.2.1-windows-x64.zip` | Extract the whole folder and open `nookly.exe` (a lone exe without the `dll` and `data` files won't start) |
| Linux x64 | `nookly-0.2.1-linux-x64.tar.gz` + [install-linux.sh](install-linux.sh) | `curl -fsSL https://raw.githubusercontent.com/nooklyru/nookly-release/main/install-linux.sh \| bash` |
| Web version | — | Open [nooklyru.github.io/nookly-release](https://nooklyru.github.io/nookly-release/), no download needed |
| Website | — | [Open nookly.ru](https://nookly.ru/) |
