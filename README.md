# Nookly

Всё, что вы пишете, остаётся у вас. Без аккаунта. Без облака. Без интернета.

Nookly — страницы, блоки, таблицы и канбан-доски в одном лёгком приложении. Открывается мгновенно, потому что ничего никуда не стучится.

Исходный код закрыт. Этот репозиторий — витрина продукта и заметки к релизам.

**Текущая версия:** [v0.1.0](https://github.com/notchy-ru/nookly-release/releases/tag/v0.1.0) · [changelog](CHANGELOG.md)

## Что внутри

- **Пишите как удобно** — текст, заголовки, списки, чекбоксы, цитаты, разделители, код с подсветкой, картинки. Слэш-команда меняет тип блока на лету, без мыши.
- **Организуйте без границ** — дерево страниц любой глубины, эмодзи-иконки, перетаскивание одним движением.
- **Смотрите на данные по-своему** — одна база, два вида: таблица для деталей, канбан для темпа работы.

![Nookly — таблица и канбан-доска](PASTE_URL_KANBAN)

- **Находите за секунду** — `Ctrl+K` ищет по всем страницам и блокам, даже по части слова.

![Nookly — поиск](PASTE_URL_SEARCH)

- **Работает без сети** — ни один байт не уходит на сторону. То, что вы написали в самолёте, никуда не денется на земле.
- **Подстраивается под вас** — светлая и тёмная тема, боковая панель прячется на узких экранах.

Платформы: **Windows**, **Linux**, **браузер**.

## Скачать

Один архив — и приложение готово. Файлы в [Releases](https://github.com/notchy-ru/nookly-release/releases).

| Платформа | Файл | Как запускать |
|---|---|---|
| Windows x64 | `nookly-0.1.0-windows-x64.zip` | Распаковать папку целиком и открыть `nookly.exe` (один exe без `dll` и `data` не запустится) |
| Linux x64 | `nookly-0.1.0-linux-x64.tar.gz` + [install-linux.sh](install-linux.sh) | `curl -fsSL https://raw.githubusercontent.com/notchy-ru/nookly-release/main/install-linux.sh \| bash` |
