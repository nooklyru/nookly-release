Nookly — страницы, блоки, таблицы и канбан-доски в одном лёгком приложении. Открывается мгновенно, потому что ничего никуда не стучится.

Исходный код закрыт. Этот репозиторий — витрина продукта и заметки к релизам.

**Данные хранятся локально в SQLite.** Файл базы можно скопировать, перенести и открыть на другом компьютере хоть через год — работает без сети и без аккаунта.

---

## Пишите так, как думаете

Текст, заголовки, списки, чекбоксы, цитаты, разделители, код с подсветкой, картинки. Слэш-команда меняет тип блока на лету, без мыши.

## Что ещё внутри

- **Дерево страниц** — любой глубины, с эмодзи-иконками и перетаскиванием
- **Офлайн** — ни один байт не уходит на сторону
- **Адаптивный интерфейс** — боковая панель прячется на узких экранах

## Скачать

Один архив — и приложение готово. Файлы в [Releases](https://github.com/notchy-ru/nookly-release/releases).

| Платформа | Файл | Как запускать |
|---|---|---|
| Windows x64 | `nookly-0.1.0-windows-x64.zip` | Распаковать папку целиком и открыть `nookly.exe` (один exe без `dll` и `data` не запустится) |
| Linux x64 | `nookly-0.1.0-linux-x64.tar.gz` + [install-linux.sh](install-linux.sh) | `curl -fsSL https://raw.githubusercontent.com/notchy-ru/nookly-release/main/install-linux.sh \| bash` |
